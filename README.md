📖 About the Project

RTK Devil Bike Taxi is a full-stack bike taxi booking and ride management platform built using Android (Kotlin) and Python Flask.

The platform connects customers and riders through an Android application and a backend REST API.

🛠️ Technologies Used

- Kotlin
- Android SDK
- XML Layouts
- Python
- Flask REST API
- SQLAlchemy
- SQLite
- Retrofit
- Kotlin Coroutines
- Gradle

📱 Main Features

👤 Customer

- Registration and Login
- Bike Taxi Ride Booking
- Ride Status Management
- Pickup OTP Verification
- Ride History
- Ratings and Reviews

🏍️ Rider

- Registration and Login
- Online / Offline Status
- Available Ride Requests
- Accept Ride Requests
- Active Ride Management
- Pickup OTP Verification
- Ride Completion and Cancellation
- Ride History

🔄 Ride Workflow

1. Customer requests a ride.
2. Rider views available requests.
3. Rider accepts the ride.
4. Pickup process begins.
5. Customer pickup OTP is verified.
6. Ride starts and gets completed.
7. Customer can submit a rating and review.
